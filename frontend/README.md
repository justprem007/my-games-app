# My Games App

A collection of Combinatorial Game Theory (CGT) games.

Live Demo: [https://gamesofnochance.netlify.app/](https://gamesofnochance.netlify.app/)

## Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher)
- npm (usually comes with Node.js)

## Getting Started

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

   This will open the application in your default browser at [http://localhost:3000](http://localhost:3000).

## Building for Production

To create an optimized production build:

```bash
cd frontend
npm run build
```

The build artifacts will be stored in the `frontend/build` directory.
